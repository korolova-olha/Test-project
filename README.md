## Структура
- **docs/** — документы, лекции, инструкции  
- **data/** — исходные материалы, таблицы  
- **drafts/** — черновики и временные версии  
- **resources/** — иллюстрации, презентации, вспомогательные файлы  
- **notes/** — заметки, комментарии, доп.информация
